# 漢字クイズ 2分チャレンジ

小学1〜6年生の漢字(1026字)の「読み方」→「部首」を4択で連続出題するクイズ。`index.html` を開くだけで遊べます。

- 正解 +1 / まちがい −1、制限時間 2分
- ポイントと残り時間をリアルタイム表示
